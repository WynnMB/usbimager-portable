# usbimager-portable

This repository provides **usbimager** in a single portable ELF file, with no extra files such as icons, manuals or shortcuts included. The official release ZIP includes these unnecessary items, but here you'll find streamlined downloads for portable use.

I recommend using the **GTK version**, as it is more elegant and should work natively in **Wayland**. Only use the **X11 version** if the GTK version isn't compatible with your setup, or if you are on an **ARM device**, as the GTK version is currently available only for **x64** architectures.
